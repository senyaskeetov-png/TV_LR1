# Лабораторная работа №1 по теории вероятностей

Жарихин А. И., группа N3251. Преподаватель - Симонян В. А.

Объект - пустая открытая банка Monster 0,5 л. Основная серия: 100 бросков с высоты примерно 15-20 см на коврик для мыши на столе. Записывалось первое касание. Получилось: верх - 21, низ - 32, бок - 47.

## Файлы

- [Отчёт PDF](Отчет_ТВ_ЛР1_Жарихин_N3251.pdf) и [Word](Отчет_ТВ_ЛР1_Жарихин_N3251.docx).
- `simulation.py` - обработка замеров и моделирование 100 000 бросков.
- `plots.py` - графики и анимация. Вызывается из `simulation.py`.
- `throws_main.json` - основная серия на коврике.
- `throws_preliminary.json` - предыдущие 100 бросков на кровати. В основную выборку не включены.
- `results.json` - результаты расчётов и исходы компьютерных бросков.
- `graphs/` - графики, кадры движения и GIF.
- `assignment.pdf` - задание.

## Запуск

Нужен Python 3. В этой папке выполнить:

```sh
python -m pip install -r requirements.txt
python simulation.py
```

Файлы `results.json` и `graphs/` будут пересозданы. Начальное число генератора фиксировано, поэтому результаты повторяются.

## Что принято в модели

Исходная гипотеза по площадям: верх - 0,08248035, низ - 0,08248035, бок - 0,83503930. Основные замеры с ней не согласуются.

В компьютерной модели банка вращается в одной вертикальной плоскости и падает под действием тяжести до первого касания. Угол выбирается от 0 до 2π, угловая скорость - от −8 до 8 рад/с, зазор - от 15 до 20 см. Угол и скорость в опыте не измерялись: это упрощения программы, а не установленные свойства бросков. Обод делится между основанием и боком по условному порогу 45°. Компьютерные частоты не обязаны совпадать с моделью по площадям.
